# ETF Radar

Watchlist ETF con score tecnico v4 e dati di mercato Yahoo Finance (ritardati).

## Uso online (GitHub Pages)

Dopo aver abilitato Pages su questo repo (Settings → Pages → Branch: main):

https://pierpaparella-del.github.io/etf-radar/

## Uso locale

```bash
python3 -m http.server 8080
```

Apri `http://localhost:8080`

**Non aprire come file://** — CORS blocca Yahoo Finance.
